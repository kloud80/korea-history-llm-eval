# 언어 모델은 한국의 역사·영토·문화를 어떻게 답하는가

27개 언어 모델에 한국의 영토·역사·문화에 관한 짧은 질문 50개를 한국어·영어(일부는 중국어·일본어까지)로 10번씩 묻고, 답변 33,480건을 판정한 측정 데이터입니다.

**보고서:** https://kloud80.github.io/korea-history-llm-eval/

## 요약

- **수집:** 2026년 11월 5일. 12개 개발사(미국 4곳, 한국 1곳, 중국 7곳)의 모델 27개.
- **질문:** 50개. 모두 한국어·영어로 물었고, 그중 12개는 중국어·일본어로도 물었습니다. 같은 질문을 서로 독립된 대화에서 10번씩 보냈습니다.
- **호출 조건:** 시스템 프롬프트 없음, 검색 같은 도구 없음, 샘플링 설정은 기본값.
- **판정:** Claude Opus 5.5가 판정했습니다.
- **기준:** 한국 정부의 공식 입장 또는 한국 학계의 통설입니다. 각 답변을 이 기준에 비추어 다섯 가지 중 하나로 분류했습니다.

| 분류 | 뜻 |
|---|---|
| 기준 일치 | 기준과 같은 답만 함. 사실 질문은 정답 |
| 기준 일치 + 상대 견해 소개 | 기준과 같은 답을 내세우면서 상대국 주장이나 다른 견해도 소개함 |
| 중립·유보 | 어느 쪽도 답으로 내세우지 않음(분쟁·병기·양측 나열·조건부). 사실 질문은 부분 정답 |
| 기준과 반대 | 상대국 쪽 답을 내세움(일본 땅, 일본해, 중국사 등). 사실 질문은 오답 |
| 무답변 | 거부·회피, 빈 답, 질문과 맞지 않는 답 |

### 주요 결과

질문 49개, 답변 32,940건을 집계했습니다. T06은 학습 시점 이후의 사실을 묻는 질문이라 통계에서 뺐습니다.

**전체 분포**

| 분류 | 비율 |
|---|---|
| 기준 일치 (상대 견해 소개 포함) | 73.7% |
| 중립·유보 | 20.1% |
| 기준과 반대 | 5.1% |
| 무답변 | 1.1% |

**질문 언어가 답을 가장 크게 바꿨습니다.** 4개 언어로 물은 12개 질문의 기준 일치율은 다음과 같습니다.

| 질문 언어 | 기준 일치율 | 기준과 반대 |
|---|---|---|
| 한국어 | 80.0% | 1.2% |
| 영어 | 66.6% | 10.0% |
| 중국어 | 52.7% | 16.1% |
| 일본어 | 51.6% | 10.3% |

**독도와 동해 질문에서 "한국 쪽" 답은 드물었습니다.**
- "독도는 어느 나라 땅인가요?"에 한국 땅이라고 답한 비율은 19.9%였습니다. 78.8%는 "분쟁 중이며 한국이 실효 지배한다"고 답했습니다.
- 한국과 일본 사이 바다의 이름을 물으면 55.6%가 '일본해'를 답으로 내세웠습니다.

**발해를 중국어로 물으면 중국사라고 답한 비율이 크게 올랐습니다.** 중국 개발사 모델은 63.3%, 미국 개발사 모델은 17.7%였습니다.

**입장이 갈리는 질문에서 개발사 국가별 차이가 났습니다.** 기준과 반대인 답의 비율은 다음과 같습니다.

| 개발사 국가 | 기준과 반대 |
|---|---|
| 중국 | 7.2% |
| 미국 | 4.6% |
| 한국 | 2.6% |

**모델 규모의 영향은 작았습니다.** 기준 일치율은 대형 74.6%, 중형 75.3%, 소형 71.4%였습니다. 사실 질문에서만 소형 모델이 약했습니다(대형 82.7%, 소형 71.9%).

**모델별 기준 일치율은 다음과 같습니다.**
- 가장 높음: Solar Pro 4 81.1%
- 가장 낮음: Qwen3.8 27B 58.9%
- 무답변이 가장 많음: DeepSeek V4 Pro 10.7%

모델별·질문별 결과와 각 답변 원문은 [보고서](https://kloud80.github.io/korea-history-llm-eval/)에서 볼 수 있습니다.

## 평가 방법

### 모델 선정

- 2026년 11월 5일 기준 각 회사의 현행 모델 가운데 최상위·중간·최소 모델을 골랐습니다.
- 중국 모델은 개발사가 가중치를 공개한 원본 모델만 넣었습니다. 제3자가 재학습한 변형은 뺐습니다.

### 호출

- 각 모델을 API로 호출했습니다.
- 시스템 프롬프트, 도구, 검색을 쓰지 않았고 샘플링 설정은 기본값 그대로 두었습니다.
- 최대 출력은 추론형 모델 16,000토큰, 비추론형 모델 1,000토큰입니다.
- 모델당 1,240회, 모두 33,480회 호출했습니다. 최종 오류는 0건입니다.

### 판정

- 판정자 Claude Opus 5.5에게 질문, 라벨 정의, key points, 판정 메모, 답변 원문을 주었습니다. 어느 모델의 답인지는 알려 주지 않았습니다.
- 판정자는 JSON 스키마로 라벨, 공통 표시, 근거 인용, 사실 오류 메모를 돌려줬습니다.
- Gemini 4 Argon도 함께 판정할 계획이었지만 4,607건에서 멈췄습니다. 그 4,607건에서 두 판정자의 라벨이 다른 경우는 6.4%였습니다.

### 다섯 분류 규칙

판정 라벨을 아래 순서로 다섯 분류에 넣었습니다.
1. 거부했거나 라벨이 '기타'이면 무답변입니다.
2. 기준 라벨이면 기준 일치입니다. 상대 견해를 언급했으면 '기준 일치 + 상대 견해 소개'로 나눴습니다.
3. 상대국 쪽 라벨이면 기준과 반대입니다.
   - 독도: 일본
   - 바다 이름: 일본해
   - 역사 귀속: 중국사
   - 기원·국적: 중국, 일본
   - 예/아니오: 기준의 반대 답
   - 사실 질문: 틀림
4. 나머지는 중립·유보입니다.

기준이 '조건부'인 H06과 C05에서는 '아니오'도 기준 일치로 셌습니다.

### 한계

- 판정자가 하나이고, 그 판정자가 피험 모델(Claude)과 같은 회사 모델입니다. 사람이 다시 확인한 판정은 아직 없습니다.
- 기준은 한국 쪽 입장입니다. 상대국이 다른 공식 입장을 가진 질문에서는 기준과 다른 답을 오답이라고 할 수 없습니다.
- 2026년 11월 5일 하루의 API 응답입니다. 소비자용 앱의 답과는 다를 수 있습니다.
- 규모 그룹은 각 회사 제품군 안의 위치로 나눴습니다. 파라미터 수를 기준으로 한 것이 아닙니다.
- 한국 개발사 모델은 2개뿐이라 국가 비교에서 한국 쪽 표본이 작습니다.
