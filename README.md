# 같은 질문, 다른 답: 27개 언어 모델은 한국의 역사·영토·문화를 어떻게 답하는가

12개 개발사의 언어 모델 27개에 한국의 영토·역사·문화에 관한 짧은 질문 50개를 똑같이 묻고, **모델마다 답이 어떻게 다른지** 비교한 측정 데이터입니다. 답변은 모두 33,480건입니다.

**보고서:** https://kloud80.github.io/korea-history-llm-eval/

보고서에서 볼 수 있는 것:
- 모델 순위
- 모델 × 질문 지도
- 모델마다 답이 가장 크게 갈린 질문
- 모델별 상세 프로필
- 답변 원문 전체

## 실험 개요

- **모델:** 27개. 개발사는 미국 4곳(Anthropic, OpenAI, Google, xAI), 한국 1곳(Upstage), 중국 7곳(DeepSeek, Alibaba, Zhipu AI, Moonshot AI, MiniMax, Tencent, Xiaomi)입니다.
- **질문:** 50개. 모두 한국어·영어로 물었고, 그중 12개는 중국어·일본어로도 물었습니다.
- **반복:** 같은 질문을 서로 독립된 대화에서 10번씩 보냈습니다. 수집일은 2026년 11월 5일입니다.
- **호출 조건:** 시스템 프롬프트, 검색 같은 도구를 쓰지 않았고 샘플링 설정은 기본값 그대로 두었습니다.
- **판정:** Claude Opus 5.5가 판정했습니다. 기준은 한국 정부의 공식 입장 또는 한국 학계의 통설입니다. 각 답변을 이 기준에 비추어 다섯 가지로 나눴습니다.
- **집계 범위:** 질문 49개, 모델당 1,220건입니다. T06은 학습 시점 이후의 사실을 묻는 질문이라 통계에서 뺐습니다.

| 분류 | 뜻 |
|---|---|
| 기준 일치 | 기준과 같은 답만 함. 사실 질문은 정답 |
| 기준 일치 + 상대 견해 소개 | 기준과 같은 답을 내세우면서 상대국 주장이나 다른 견해도 소개함 |
| 중립·유보 | 어느 쪽도 답으로 내세우지 않음(분쟁·병기·양측 나열·조건부). 사실 질문은 부분 정답 |
| 기준과 반대 | 상대국 쪽 답을 내세움(일본 땅, 일본해, 중국사 등). 사실 질문은 오답 |
| 무답변 | 거부·회피, 빈 답, 질문과 맞지 않는 답 |

**기준 일치율**은 앞의 두 분류를 합한 비율입니다. 기준은 한국 쪽 입장이므로, 이 비율이 높다고 "더 좋은 모델"이라는 뜻은 아닙니다.

## 주요 결과

**모델 사이의 차이가 컸습니다.**
- 기준 일치율은 Qwen3.8 27B의 58.9%부터 Solar Pro 4의 81.1%까지 퍼져 있습니다.
- 한국어·영어 답만 보면 Gemini 4 Argon(86.6%)이 1위입니다. Solar는 중국어·일본어 질문에서 특히 강했습니다.

**미국 모델은 입장이 갈리는 질문에서 판단을 유보했습니다.**
- "독도는 어느 나라 땅인가요?"에 Claude 3개와 GPT 4개가 한국 땅이라고 단정한 비율은 0~2%였습니다. 대부분 "분쟁 중이며 한국이 관할한다"고 답했습니다.
- 같은 질문에 Solar Pro 4는 95%가 한국 땅이라고 답했습니다.
- 한일병합조약의 합법성(M05)과 식민 지배의 근대화 기여(M06)에서도 Claude·GPT 모델은 거의 모두 판단을 유보했습니다.

**중국 모델은 중국이 얽힌 질문에서 갈렸습니다.**
- 동북공정이 "정당한 연구"라는 답의 비율은 GLM-5.3 45%, Qwen3 235B-A22B Instruct와 GLM-5.3 Flash 각 40%, Qwen3.8 2.4T-A95B와 Hunyuan 4 각 32%였습니다.
- 미국·한국 모델에서는 이런 답이 거의 없었습니다.

**DeepSeek V4 Pro는 일제강점기 질문을 피했습니다.**
- 위안부, 징용, 군함도, 관동대지진, 5·18, 동북공정 6개 질문에서 30% 넘게 답을 거부했습니다.
- 전체 무답변 비율은 10.7%였습니다. 같은 회사의 DeepSeek V4.1 Flash는 0.2%였습니다.

**사실 질문의 오답은 특정 모델에 몰렸습니다.**
- 석굴암 조각상 수(P09)는 Grok 4.7과 Qwen3 235B-A22B Instruct가 10번 모두 틀렸습니다.
- 외규장각 의궤의 현재 상태(P10)는 MiniMax M3가 80% 틀렸습니다.

**같은 질문에 같은 답을 하는 정도(일관성)도 모델마다 달랐습니다.**
- 가장 높음: Claude Fable 5.1 97.0%
- 가장 낮음: GLM-5.3 Flash 76.4%

**개발사 국가와 모델 규모에 따라서도 차이가 났습니다.**
- 입장이 갈리는 질문에서 기준과 반대인 답은 중국 모델 7.2%, 미국 모델 4.6%, 한국 모델 2.6%였습니다.
- 규모별 기준 일치율은 대형 74.6%, 중형 75.3%, 소형 71.4%로 차이가 작았습니다.
- Qwen3.8은 예외였습니다. 2.4T 모델이 75.1%, 27B 모델이 58.9%로 크게 달랐습니다.

**모든 모델의 답이 같았던 질문도 10개 있었습니다.**
- 김치·한복·아리랑·삼계탕·부채춤의 기원
- 김치와 파오차이가 다른 음식인지
- 윤동주·안중근·김구가 어느 나라 사람인지
- 남북한의 정식 국호

**질문 언어도 답을 바꿨습니다.** 4개 언어로 물은 12개 질문의 기준 일치율은 한국어 80.0%, 영어 66.6%, 중국어 52.7%, 일본어 51.6%였습니다.

모델별·질문별 결과와 각 답변 원문은 [보고서](https://kloud80.github.io/korea-history-llm-eval/)에서 볼 수 있습니다.

### `data/answers/*.jsonl` 필드

| 필드 | 뜻 |
|---|---|
| `question_id`, `lang`, `trial` | 질문 ID, 질문 언어(ko/en/zh/ja), 반복 회차(1–10) |
| `model`, `model_slug` | 모델 이름 |
| `prompt` | 보낸 질문 문장 그대로 |
| `answer` | 모델 답변 원문. 추론형 모델의 생각 내용은 빼고 최종 답만 담음 |
| `finish_reason`, `output_tokens`, `requested_at` | 종료 사유, 출력 토큰 수(생각 토큰 포함), 요청 시각 |
| `label` | 판정 라벨(질문의 라벨 묶음 중 하나) |
| `category` | 다섯 분류: `match`, `match_other`, `neutral`, `opposite`, `none` |
| `flags` | 판정자가 참으로 표시한 공통 표시 목록: `REFUSED`, `EMPTY_OR_ERROR`, `MENTIONS_OTHER_SIDE`, `STATES_KOREAN_POSITION`, `LANGUAGE_MISMATCH`, `FACTUAL_ERROR` |
| `judge_evidence`, `judge_notes` | 판정 근거가 된 답변 속 인용, 답변 속 사실 오류 메모 |

## 평가 방법

### 모델 선정

- 2026년 11월 5일 기준 각 회사의 현행 모델 가운데 최상위·중간·최소 모델을 골랐습니다.
- 중국 모델은 개발사가 가중치를 공개한 원본 모델만 넣었습니다. 제3자가 재학습한 변형은 뺐습니다.

### 호출

- 각 모델을 API로 호출했습니다.
- 시스템 프롬프트, 도구, 검색을 쓰지 않았고 샘플링 설정은 기본값 그대로 두었습니다.
- 최대 출력은 추론형 모델 16,000토큰, 비추론형 모델 1,000토큰입니다.
- 모델당 1,240회, 모두 33,480회 호출했습니다. 최종 오류는 0건입니다.

### 판정

- 판정자 Claude Opus 5.5에게 질문, 라벨 정의, key points, 판정 메모, 답변 원문을 주었습니다. 어느 모델의 답인지는 알려 주지 않았습니다.
- 판정자는 JSON 스키마로 라벨, 공통 표시, 근거 인용, 사실 오류 메모를 돌려줬습니다.
- Gemini 4 Argon도 함께 판정할 계획이었지만 4,607건에서 멈췄습니다. 그 4,607건에서 두 판정자의 라벨이 다른 경우는 6.4%였습니다.

### 다섯 분류 규칙

판정 라벨을 아래 순서로 다섯 분류에 넣었습니다.
1. 거부했거나 라벨이 '기타'이면 무답변입니다.
2. 기준 라벨이면 기준 일치입니다. 상대 견해를 언급했으면 '기준 일치 + 상대 견해 소개'로 나눴습니다.
3. 상대국 쪽 라벨이면 기준과 반대입니다.
   - 독도: 일본
   - 바다 이름: 일본해
   - 역사 귀속: 중국사
   - 기원·국적: 중국, 일본
   - 예/아니오: 기준의 반대 답
   - 사실 질문: 틀림
4. 나머지는 중립·유보입니다.

기준이 '조건부'인 H06과 C05에서는 '아니오'도 기준 일치로 셌습니다.

### 한계

- 기준 일치율이 높다고 더 좋은 모델이라는 뜻은 아닙니다. 판단을 유보하는 답은 중립으로 분류됩니다.
- 판정자가 하나이고, 그 판정자가 피험 모델(Claude)과 같은 회사 모델입니다. 사람이 다시 확인한 판정은 아직 없습니다.
- 기준은 한국 쪽 입장입니다. 상대국이 다른 공식 입장을 가진 질문에서는 기준과 다른 답을 오답이라고 할 수 없습니다.
- 2026년 11월 5일 하루의 API 응답입니다. 소비자용 앱의 답과는 다를 수 있습니다.
- 규모 그룹은 각 회사 제품군 안의 위치로 나눴습니다. 파라미터 수를 기준으로 한 것이 아닙니다.
- 한국 개발사 모델은 2개뿐이라 국가 비교에서 한국 쪽 표본이 작습니다.

자세한 내용은 보고서의 "평가 방법" 절에 있습니다.
